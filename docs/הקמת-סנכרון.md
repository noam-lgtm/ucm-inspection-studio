# הקמת שרת הסנכרון (פעם אחת, כ-15 דקות)

השרת שומר את המוצרים, הדוחות וקובצי ה-PDF, כך שכל מחשב רואה את אותם נתונים. הוא רץ ב-Cloudflare בתוכנית החינמית: בלי כרטיס אשראי, בלי תשלום חודשי.

## מה צריך מראש

1. **חשבון Cloudflare חינמי**: נרשמים ב-https://dash.cloudflare.com/sign-up עם כתובת אימייל. לא מבקשים כרטיס אשראי.
2. **Node.js** על המחשב שלך (לא של בן הדוד): https://nodejs.org ← להוריד ולהתקין את גרסת ה-LTS. אחרי ההתקנה פותחים "שורת פקודה" (Windows: להקליד `cmd` בתפריט התחל).
3. עותק של הפרויקט על המחשב: ב-GitHub לוחצים **Code ← Download ZIP** ופותחים את הקובץ, או `git clone`.

## ההקמה: שלוש פקודות

בשורת הפקודה נכנסים לתיקיית `worker` שבתוך הפרויקט, ומריצים:

```
npm install
npx wrangler login
node setup.mjs
```

- הפקודה השנייה פותחת דפדפן ומבקשת לאשר את החיבור לחשבון Cloudflare. לוחצים **Allow**.
- הפקודה השלישית שואלת איזו סיסמת כניסה לתת לחברה (לפחות 16 תווים, למשל `ucm-bdika-yavne-2026`; Enter מייצר סיסמה אקראית), ואז עושה את כל השאר לבד: יוצרת מסד נתונים ואחסון קבצים ומעלה את השרת. בסוף היא מדפיסה:

```
כתובת שרת הסנכרון: https://ucm-inspection-sync.XXXX.workers.dev
מפתח גישה:         3f9a...
```

אפשר להריץ את `node setup.mjs` שוב בכל עת; הוא לא יוצר כפילויות.

## נעילת האתר בסיסמה (פעם אחת)

כדי שהאתר יבקש את הסיסמה בכניסה, ב-GitHub פותחים את הקובץ `src/config.js`, לוחצים על העיפרון (Edit), ומחליפים את השורה `syncUrl: '',` בשורה שהסקריפט הדפיס, למשל:

```
syncUrl: 'https://ucm-inspection-sync.XXXX.workers.dev',
```

לוחצים **Commit changes**. תוך דקה האתר מתעדכן: בכניסה מופיע מסך נעילה, ומי שאין לו את הסיסמה לא רואה כלום. הסיסמה נבדקת מול השרת ולא ניתנת לעקיפה מהדפדפן.

## חיבור האפליקציה (בכל מחשב שמשתמש בה)

1. פותחים את האתר ← מסך הנעילה ← מקלידים את הסיסמה ← **כניסה**. זה נשמר במחשב; לא צריך להקליד שוב.
2. מרגע זה כל מוצר או דוח שנשמר מופיע בכל המחשבים תוך שניות, והשרת שומר גיבוי מלא כל לילה.
3. יציאה (למשל במחשב משותף): **הגדרות** ← **יציאה מהמערכת במחשב זה**.

## שאלות נפוצות

- **צריך לעשות משהו באופן שוטף?** לא. אין תחזוקה, אין חידוש, אין תשלום.
- **איפה הנתונים?** במסד הנתונים ובאחסון של החשבון שלך ב-Cloudflare. אפשר לראות אותם ב-dash.cloudflare.com תחת Workers & Pages / D1 / R2.
- **המפתח דלף?** מריצים בתיקיית `worker`: `npx wrangler secret put WORKSPACE_KEY` ומקלידים מפתח חדש, ואז מעדכנים אותו בהגדרות בכל מחשב.
- **רוצים קריאה חזותית (AI) של טפסים שהמידות בהם הן תמונות?** אופציונלי ובתשלום לפי שימוש (רק בייבוא, פעם אחת למק"ט). בתיקיית `worker`: `npx wrangler secret put ANTHROPIC_API_KEY` ומדביקים מפתח מ-console.anthropic.com. בלי זה ממלאים את המידות לפי התמונות שהאפליקציה מציגה.
- **המגבלות של התוכנית החינמית**: 100,000 פניות ביום, 5GB מסד נתונים, 10GB קבצים. דוח שוקל כ-5KB ו-PDF כ-0.5MB, כלומר עשרות אלפי דוחות.
